# Prep World - Feature Roadmap

| Feature | Description | Status / Notes |
| --- | --- | --- |
| **Word History & Bookmarks** | Track searched words with timestamps, allow bookmarking favorites | Planned |
| **Export & Share** | Export word lists to CSV/PDF, share results via link | Planned |
| **Word Comparison** | Side-by-side comparison of two words (definitions, synonyms) | Planned |
| **Daily Streak & Gamification** | Track daily usage streaks, achievement badges | Planned |
| **Advanced Analytics** | Charts for search patterns, most-searched words, usage heatmaps | Planned |
| **Keyboard Shortcuts** | Power-user keyboard shortcuts (Ctrl+K for search, etc.) | Planned |
| **Word Categories/Tags** | Organize words by categories (emotions, nature, academic) | Planned |
| **Pronunciation Audio Recorder** | Record and compare your pronunciation | Planned |
| **Multi-language Support** | i18n for the UI interface | Planned |
| **Offline Mode (PWA)** | Service worker for offline dictionary access | Planned |
| **Peddabala Siksha** | Later scrape from that data | Planned |
| **Scrabble Game** | Interactive word game | Planned |
| **Personalized Learning** | Adapt tracking and word presentation accordingly | Planned |
| **Word Explorer** | Every word from dictionary: synonym, word parts, origin story, pronunciation, sentence, definition | Core Feature |
| **Voice Search & Speaker** | Audio input and audio text-to-speech output | Planned |
| **Spell Training** | Teach with exercises, prepare materials starting from 1925 standards | Planned |
| **Parent Controls & Analysis** | Review practicing types and speaker data | Planned |
| **Typing Practice** | Typing exercises (Hemu system) | Planned |
| **Results tracking** | Comprehensive history tracking visited vs. non-visited words | Planned |
| **Word Training Cycles** | Train words adaptively; next words should follow a cyclic pattern | Planned |
| **Worksheets & Drills** | Generate various worksheets with drills; student and parent versions | Planned |
| **Grade Personalization** | Personalize results and difficulty according to grade/standards | Planned |
| **Links** | Resource and reference link management | Planned |
| **Translation to Story** | Voice translation for various languages into story formats | Planned |
| **AI Chatbot Integration** | Practical, interactive assistant for word help | Planned |
| **Efficient Performance** | Ensure a fast, optimized website experience | Core Target |
| **Puzzles** | Passage-based questions and reading puzzles | Planned |
| **Maths & Science** | Drills, quizzes, and core concept integration | Future Expansion |
| **Mobile & iPad App** | Dedicated mobile responsive layouts or native apps | Future Expansion |
